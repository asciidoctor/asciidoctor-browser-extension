== Job Status at a Glance

Ferry's dashboard uses a small set of icons consistently across the CLI, the web UI, and alert
messages, so on-call engineers only have to learn them once:

[cols="1,3", options="header"]
|===
|Status |Meaning

|icon:check-circle[role=green] `succeeded`
|The handler returned without raising.

|icon:sync[role=blue] `running`
|A worker currently holds the lease.

|icon:exclamation-triangle[role=yellow] `retrying`
|Handler raised and Ferry rescheduled it, retries remain.

|icon:times-circle[role=red] `dead-lettered`
|Handler raised and Ferry ran out of retries.
|===

TIP: A healthy cluster shows almost nothing but icon:check-circle[role=green]. If
icon:exclamation-triangle[role=yellow] rows start dominating your dashboard, check
<<_troubleshooting_and_faq>> before you check the retry count.
